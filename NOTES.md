## Git Basics

| Command | What it does |
| --- | --- |
| `git status` | Show changed files |
| `git add <file>` | Stage a file |
| `git commit -m "msg"` | Save staged changes |
| `git push` | Upload commits to GitHub |
| `git pull` | Download the latest changes |
